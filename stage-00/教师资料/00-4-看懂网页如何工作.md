# 00-4 教师准备与验收

## 发布前准备

- 确认学生已将 00-3 文件夹推送至个人仓库 `main`，并在任务平台提交仓库链接或任务文件夹位置。
- 提醒学生使用统一的 `任务总结模板.md`，只需记录请求证据和简短解释。
- starter 使用 `python -m http.server 8000` 提供本地同源文件，`app.js` 请求相对地址 `message.json`。建议在课程常用 Windows 环境预先试运行。
- 提醒学生不要双击 `index.html` 以 `file://` 打开；此时浏览器可能因跨源限制拦截 JSON 请求。应从 `web-demo` 目录启动服务器，并访问 `http://localhost:8000`。示例页面会在直接打开时提示这一操作。
- 提醒学生端口 8000 若被占用，可按教师补充说明使用其他端口；访问地址的端口必须同步修改。
- 本任务不要求账号登录、跨域配置、外部 API 或任何密钥。

## 验收标准

| 项目 | 通过表现 |
| --- | --- |
| 页面修改 | HTML 内容与 CSS 样式至少各有一处有意义修改 |
| 网络观察 | 能找到 `message.json` 请求并记录方法、状态码和响应字段 |
| 概念理解 | 能说明 HTML、CSS、JavaScript 的职责 |
| 数据流 | 能解释浏览器发请求、服务器返回 JSON、页面显示结果 |
| AI 核验 | `任务总结.md` 用一句话说明如何用页面证据核对 AI 解释 |
| GitHub | `00-4-看懂网页如何工作` 文件夹已推送到个人仓库 `main`，教师可访问 |

状态码、内容以学生本地实际运行结果为准。环境差异造成的端口问题不影响概念验收。学生直接把本任务文件夹推送到个人仓库 `main`，阶段 00 完成。
