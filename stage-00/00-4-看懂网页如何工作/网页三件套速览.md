# 网页三件套速览(任务 00-4)

不用背。做任务时看不懂就回来查。这一页里的例子都来自 `web-demo` 里的文件。

## 一、三个文件,三种分工

把网页想成一个人:

| 文件 | 比喻 | 负责什么 | 在示例中 |
| --- | --- | --- | --- |
| `index.html`(HTML) | 骨架 | 页面里**有什么**:标题、文字、按钮 | `<h1>` 是标题,`<button>` 是按钮 |
| `styles.css`(CSS) | 外观 | 页面**长什么样**:颜色、字体、间距 | `h1 { color: ... }` 决定标题颜色 |
| `app.js`(JavaScript) | 动作 | 点击之后**发生什么** | 点按钮 → 请求数据 → 显示消息 |

还有一个文件不属于三件套:`message.json` 是**数据**,它是服务器要交给浏览器的内容。

## 二、它们怎么连在一起

`index.html` 是入口。浏览器先读它,再按里面的两行引用去找另外两个文件:

```html
<link rel="stylesheet" href="styles.css">   <!-- 去找外观 -->
<script src="app.js"></script>              <!-- 去找动作 -->
```

HTML 里的 `id="load-message"` 是按钮的"名牌"。JavaScript 用它找到按钮,CSS 也可以用它指定样式。

## 三、点击按钮之后发生了什么

```text
你点击按钮
  → app.js 里的 JavaScript 被触发
  → 浏览器向服务器发出请求:要 message.json
  → 本地服务器(终端里运行的 python -m http.server)找到这个文件,返回内容
  → JavaScript 取出里面的 message,写进页面
  → 你看到消息
```

在开发者工具的 Network 标签里,你能亲眼看到这一次请求和它的回复。

## 四、请求和响应里的几个词

| 词 | 白话 | 本任务里会看到 |
| --- | --- | --- |
| 请求方法 | 想怎么拿数据 | `GET`(单纯"取一份") |
| 状态码 | 服务器告诉你的结果 | `200` 成功;`304` 没变化,用缓存;`404` 找不到文件 |
| 响应 | 服务器返回的内容 | `message.json` 的内容 |
| JSON | 一种带标签的数据格式,和 Python 的字典很像 | `{"message": "..."}`,取值用标签 `message` |

状态码说明:第一次请求通常是 200。再次请求同一个没变化的文件,浏览器可能显示 `304` 或"(disk cache)",这是正常的缓存现象,不是错误。

## 五、开发者工具怎么用

按 `F12` 打开。本任务主要用两个标签:

| 标签 | 用来看什么 |
| --- | --- |
| Network(网络) | 页面发出了哪些请求,每个请求的方法、状态码、响应内容 |
| Elements(元素) | 页面的 HTML 结构和每个元素生效的 CSS |

在 Network 里找请求的小技巧:

1. **先打开开发者工具,再操作页面**,否则不会记录。
2. 勾选 **Disable cache**(禁用缓存),状态码就更稳定。
3. 点一下"清空"(🚫图标),再点按钮,列表里只会出现这一次的新请求。
4. 筛选里选 **Fetch/XHR**,只看 JavaScript 发出的请求,`message.json` 就在里面。
5. 点击 `message.json`,在右侧分别看 Headers(方法、状态码)和 Response(返回内容)。

## 六、遇到问题怎么办

先自己排查(读 Console 报错、看 Network),实在没有思路再对照下表。

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 点按钮提示"请求失败",Console 里出现 CORS 报错,地址栏以 `file:///` 开头 | 双击打开了文件,没有经过服务器,浏览器出于安全限制拦截了请求 | 关掉页面,在 `web-demo` 目录运行 `python -m http.server 8000`,在地址栏输入 `http://localhost:8000` |
| 浏览器打不开 `localhost:8000` | 终端里的服务器没在运行,或不在 `web-demo` 目录 | 回终端检查当前目录,重新运行 `python -m http.server 8000` |
| 终端提示端口被占用 | 8000 已被别的程序使用 | 改用 `python -m http.server 8001`,浏览器打开 `localhost:8001` |
| 改了文件,页面没变化 | 浏览器用了旧缓存 | 按 `Ctrl+F5` 强制刷新 |
| 点按钮显示"请求失败" | 服务器没运行,或文件名拼错 | 看终端有没有报错,看 Network 里请求的状态码 |
| `python` 命令不可用 | 命令名不同 | 试试 `py -m http.server 8000` |
