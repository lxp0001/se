不用背。读代码或做任务时遇到看不懂的写法,回来查这一页。例子与 `activity_signup.py` 对应;其中 `remove` 和 `for` 是本任务要补上的写法,`user3` 只用于说明如何向列表追加新名字。

## 一、核心概念

| 概念 | 白话 | 本程序里的例子 |
| --- | --- | --- |
| 变量 | 贴了标签的盒子,可以往里放东西 | `signed_up = sign_up(event, "user2")` |
| 文字(字符串) | 用引号括起来的文字 | `"机器人社团开放日"` |
| 整数 | 没有小数点的数字 | `2` |
| 列表 `[ ]` | 有顺序的清单 | `["user1"]` |
| 字典 `{ }` | 带标签的信息卡,用标签取内容 | `event["capacity"]` 取出 `2` |
| 布尔值 | 只有"是"和"否"两种:`True` / `False` | 报名是否成功 |
| `if` | 条件满足才做 | `if student in event["attendees"]:` |
| `for` | 清单里的每一项都做一遍 | `for name in event["attendees"]:` |
| 函数 `def` | 打包好的一套操作,起个名字反复用 | `def sign_up(event, student):` |
| 参数 | 交给函数的材料 | `event`、`student` |
| `return` | 函数交回的答案,执行到它函数就结束 | `return True` |

## 二、列表四件套(取消报名会用到)

| 写法 | 作用 | 例子(名单是 `["user1", "user2"]`) |
| --- | --- | --- |
| `名单.append(x)` | 把 x 加到末尾 | `append("user3")` 后:`["user1", "user2", "user3"]` |
| `名单.remove(x)` | 删掉 x | `remove("user2")` 后:`["user1"]` |
| `len(名单)` | 数一数有几个 | `len(名单)` 是 `2` |
| `x in 名单` | x 在不在名单里(得到 True / False) | `"user2" in 名单` 是 `True` |

注意:`remove` 要删的名字如果不在名单里,Python 会报错。所以要先用 `in` 检查。

## 三、`if` 的读法

```python
if student in event["attendees"]:   # 如果 student 在报名名单里
    return False                    #     就返回 False,函数到此结束
```

- 条件后面的冒号 `:` 不能少。
- 缩进(行首的空格)表示"属于这个 if"。缩进不对会报错。
- 条件不满足时,Python 会跳过缩进的那几行,继续往下执行。

## 四、读报错的三步

1. 看**最后一行**:它写着错误名称和原因,例如 `NameError`、`IndentationError`。
2. 往上找 `File ... line 数字`:这是出错的文件和行号。
3. 回到那一行(有时要看上一行)检查拼写、冒号、缩进。

看不懂时,把完整报错和相关代码一起发给 AI,并说明你已经试过什么。

## 五、几个小细节

- `=` 是"赋值"(把右边的值放进左边的变量),`==` 才是"判断是否相等"。
- `f"..."` 是格式化字符串:`{ }` 里的内容会被替换成变量的值。
- 函数里改了列表(例如 `append`、`remove`),函数外的同一份名单也会跟着变。所以 `remaining_seats(event)` 在报名或取消之后,结果会变。
- `if __name__ == "__main__":` 的意思是"直接运行这个文件时,从 `main()` 开始"。现在不用深究。
