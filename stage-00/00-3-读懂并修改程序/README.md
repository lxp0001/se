# 任务 00-3:读懂并修改程序

本任务用"校园活动报名"小程序,带你从零读懂 Python 的基本写法:变量与数据类型、列表和字典、条件判断、循环、函数、参数与返回值。顺序是:先运行,再动手改一改,然后读懂程序、追踪数据,最后增加"取消报名"功能并测试。重点是能解释程序为什么这样运行,而不是背语法名词。

## 完成后你应该能够

- 读懂由函数、列表和字典组成的短程序。
- 读懂变量赋值、字符串、整数、列表、字典、`if`、`for`、函数参数与返回值。
- 根据输入追踪变量值和函数返回值。
- 修改一个函数,实现取消报名。
- 用正常情况和边界情况检查自己的修改(边界情况:最容易出错的特殊情况,比如名单是空的)。

## 第四步:实现取消报名

先想清楚怎么处理两种情况,白话步骤是:

> 如果这个名字在报名名单里:把它删掉,返回 `True`。
> 否则:什么都不改,返回 `False`。

在 `cancel_signup(event, student)` 中把这两句话翻译成代码,要求:

- 若 `student` 在报名名单中,移除该名字并返回 `True`。
- 若该名字不在名单中,名单保持不变并返回 `False`。
- 取消后空出的名额应反映在 `remaining_seats(event)` 的结果中。

提示:参考 `sign_up` 里的 `if` 写法;删除名字用 `名单.remove(名字)`,先检查名字在不在名单里再删,否则会报错。

在 `main()` 的演示中增加一次成功取消和一次取消未报名者的操作。请勿重写整个程序,也不要改动函数参数或示例数据结构。

## 第五步:设计测试,检查自己的修改

至少设计并运行三个情境:成功取消、取消不存在的名字、名单为空时取消。要造不同的名单,可以直接套用下面的写法(放进 `main()` 里运行):

```python
test_event = {"name": "测试", "capacity": 2, "attendees": ["user1", "user2"]}
result = cancel_signup(test_event, "user2")
print(result, test_event["attendees"], remaining_seats(test_event))
```

把 `attendees` 和取消的名字换成其他情境的数据,再运行一次。每次运行前,先写下你预期会打印什么,再与实际结果对照。

选做:想让检查自动化,可以用 `assert`,例如 `assert result == True`;断言不成立时程序会报错并停下来。
