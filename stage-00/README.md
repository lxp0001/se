# 阶段 00：基础准备

本阶段帮助学生先走通课程的提交方式，再补齐运行程序、读代码和理解 Web 应用所需的基础。

| 编号 | 任务 | 状态 |
| --- | --- | --- |
| 00-1 | [提交第一份代码](00-1-提交第一份代码/README.md) | 已设计 |
| 00-2 | [让程序跑起来](00-2-让程序跑起来/README.md) | 已设计 |
| 00-3 | [读懂并修改程序](00-3-读懂并修改程序/README.md) | 已设计 |
| 00-4 | [看懂网页如何工作](00-4-看懂网页如何工作/README.md) | 已设计 |

每位学生使用自己的 GitHub 仓库完成课程任务。每项任务的成果放入仓库中对应的任务文件夹，并直接提交、推送到个人仓库的 `main` 分支。学生先独立尝试，再用 AI 获取建议，最后自己验证并解释结果。

教师说明集中放在 [教师资料](教师资料/README.md)，不与学生任务说明混放。

各任务的简短总结统一使用[任务总结模板](任务总结模板.md)。
