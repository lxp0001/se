# 任务 01-3：用 DBX 可视化查看数据（选做）

完成 01-2 后，可以用 DBX 打开 SQLite 数据库，直观看到程序创建的表、字段和报名记录。这个活动用于辅助观察，不增加新的编程要求，也不替代 Python 和 SQL 练习。

## 开始前

先完成 01-2，并运行 `sqlite_basics.py`，确认生成了：

```text
01-2-使用SQLite/registrations.db
```

## 可选步骤

1. 打开 [DBX](https://dbxio.com/en)，选择打开本地 SQLite 数据库，并载入 `registrations.db`。
2. 分别查看 `events` 和 `registrations` 表，观察每张表的字段和记录。
3. 在 `registrations` 表中找到 `user1` 的报名记录，再根据 `event_id` 到 `events` 表中找对应的活动名称。
4. 将看到的结果与 01-2 程序打印的查询结果对照，想一想两张表是怎样关联的。

DBX 的界面可能变化；按页面当前提供的打开数据库入口操作即可。如果无法打开，也可以跳过，不影响阶段任务完成。
