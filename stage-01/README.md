# 阶段 01：文件与数据库

本阶段从阶段 00 的 Python 基础出发，学习把数据保存到文件和 SQLite，并在两种方式中读回、查询同一份数据。贯穿例子是虚构的活动报名名单，用户名统一使用 `user1`、`user2` 等代号。

| 编号 | 任务 | 先想一想 | 学生做出的东西 | 提交内容 |
| --- | --- | --- | --- | --- |
| 01-1 | [文件存取](01-1-文件存取/README.md) | 程序关掉后，列表里的报名信息会怎样？写进文件就能保住吗？ | 修改程序、生成并读回 JSON 名单 | `file_store.py`、`registrations.json`、`任务总结.md` |
| 01-2 | [使用 SQLite](01-2-使用SQLite/README.md) | 想查“user1 报了哪些活动”，在 JSON 里要怎么做？你猜数据库能一句话做到吗？ | 建表、插入和查询代码及查询结果 | `sqlite_basics.py`、含查询结果的 `任务总结.md`；不提交 `.db` 文件 |
| 01-3（选做） | [用 DBX 可视化查看数据](01-3-可视化查看/README.md) | `events` 和 `registrations` 两张表里分别能看到什么？ | 用 DBX 打开 01-2 生成的数据库，观察表、字段和记录 | 无需额外提交；不提交 `.db` 文件 |

## 阶段约定

- 01-1、01-2 先独立写预测，再运行、观察证据并解释；在任务总结里用一句话回顾“我的预测对不对”。01-3 为选做观察活动。
- 按上表把必交文件放入个人仓库中对应的任务文件夹；不提交 SQLite 生成的 `.db`、`.sqlite` 或 `.sqlite3` 文件。
- 使用虚构姓名和活动，不录入同学、家人或其他真实人员的个人信息。
- 沿用阶段 00 的 `.gitignore`。SQLite 数据库是本地生成文件，不提交数据库二进制文件；提交代码、JSON 数据和文字结果即可。
- **选做：**任务 01-3 使用 [DBX](https://dbxio.com/en) 图形化查看 01-2 创建的本地 SQLite 数据库；不能代替 Python/SQL 编程。
- 不在程序、JSON、截图或提交记录中放密码、API Key、Token 等秘密。本阶段无需任何密钥。
- 每项任务放入个人仓库对应目录，按阶段 00 的方式提交到个人仓库 `main` 分支。

## 完成标准

能够说明 JSON 文件如何保存和读回数据；能够用 SQLite 建表、插入和查询。DBX 可视化查看是选做的辅助活动，不影响阶段核心任务完成。
