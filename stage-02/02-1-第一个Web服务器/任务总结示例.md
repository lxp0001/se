# 任务总结示例：02-1 启动第一个 Web 服务器

> 这是一份格式示例。运行结果请以你自己电脑上的实际观察为准；`/docs` 的资料来源也要自己打开核对。

- **开始前我的判断：** 我猜只要 FastAPI 服务正在运行，访问根路径就会得到 JSON；如果服务关闭，浏览器就无法取得新的响应。
- **我观察到的证据：** 我访问 `GET http://127.0.0.1:8000/`，页面返回状态码 `200` 和 `{"message":"活动报名服务器已经启动"}`。停止服务器后再刷新，浏览器无法连接；重新启动后又能访问。
- **我现在的解释：** 浏览器是客户端，FastAPI 程序是服务器。客户端发出 GET 请求，服务器运行对应的接口函数并返回 JSON。服务器停止后，没有程序接收请求。
- **我查到的问题答案：** 我在 `main.py` 里没有找到 `/docs` 路由。查阅 FastAPI 文档后，我了解到 `/docs` 是默认提供的交互式 API 文档页面；FastAPI 也允许通过 `docs_url` 改它的网址。
