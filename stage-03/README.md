# 阶段 03：React 页面与前后端通信

本阶段直接从 React 入手，不设置单独的 JavaScript 入门阶段。学生先运行对比页面，随后搭建 React 页面并学习组件、状态和事件，最后连接阶段 02 的 FastAPI 服务，完成活动报名记录的增删改查。用到的 JavaScript 语法在 React 操作中按需解释。

| 编号 | 任务 | 先想一想 | 学生做出的东西 | 提交内容 |
| --- | --- | --- | --- | --- |
| 03-1 | [运行页面，对比原生写法与 React](03-1-对比原生与React/README.md) | 两边都能报名，点击后哪些界面会变？代码如何让它们同步？ | 运行对比、追踪一次状态变化并记录发现 | `react-vs-native.html`、`任务总结.md` |
| 03-2 | [搭建 React 活动页面](03-2-搭建React页面/README.md) | 活动列表、报名人数和筛选结果，怎样保持同步？ | 可交互的 React 活动页面 | React 项目源码、`任务总结.md` |
| 03-3 | [连接 API，完成报名 CRUD](03-3-连接API完成报名CRUD/README.md) | 刷新网页后，报名记录为什么还在？ | 从 FastAPI 读取并管理报名的 React 页面 | React 项目源码、后端必要修改、`任务总结.md` |

## 本阶段约定

- 03-1 只需打开材料并操作比较，不要求先学语法或修改代码。
- 后续任务使用 Vite 创建 React 项目；安装依赖需要 Node.js 和网络连接。具体版本要求以 [Vite 官方指南](https://vite.dev/guide/) 为准。
- 使用 `user1`、`user2` 等虚构用户名；不提交密钥、`.env` 或 `node_modules`。
- 03-3 连接阶段 02 的本地 API；部署、自动化测试和 React 路由不在本阶段范围内。
- 各任务提交到个人仓库 `main` 分支，并按任务要求记录运行证据。

## 完成标准

学生能运行并修改 React 页面，说明状态变化如何更新界面，并让页面通过 HTTP 请求读写服务器数据；不要求脱离项目背诵 JavaScript 语法。
