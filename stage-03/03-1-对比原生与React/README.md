# 任务 03-1：运行页面，对比原生写法与 React

本任务先不写代码。打开随任务提供的页面，直接操作两边的活动列表，感受原生 HTML + JavaScript 和 React 更新页面的不同方式。

## 操作

1. 双击打开 `react-vs-native.html`，或在浏览器中打开这个文件。
2. 在左右两栏分别点击“报名/取消”，勾选“只看还有名额的”，观察报名人数、顶部统计和活动列表如何变化。
3. 展开两侧的“查看完整代码”，对照正在运行的代码。

页面需要联网加载 React 和 Babel。若 React 一侧未显示，先确认网络允许访问 jsDelivr，再刷新页面。

## 小挑战：追踪一次页面变化

1. 先选一场还有名额的活动，点击“报名”。
2. 展开两侧的代码，分别找到点击按钮后运行的函数。
3. 沿着代码指出：报名人数、按钮文字和顶部统计各自是怎样更新的？原生写法里，更新几处页面分别由哪些代码负责？React 写法里，哪段代码改变状态、哪段代码根据状态显示页面？
4. 再点击“只看还有名额的”，观察名额已满的活动消失后，两种写法各自如何让列表更新。

不要求理解每个符号或术语；能指出相关代码位置，并用自己的话说清更新顺序即可。

## 记录发现

不用写长篇说明，在 `任务总结.md` 中记下：

- 两边哪一个都能完成相同功能？
- 取消或报名后，页面上有哪些地方跟着变化？
- 你观察到原生写法和 React 写法更新页面的方式有什么不同？
- 小挑战中找到的代码位置：原生版负责更新页面的函数是____；React 版负责改变状态的代码是____。

本任务只运行和观察，不要求修改 HTML、JavaScript 或 React 代码。
