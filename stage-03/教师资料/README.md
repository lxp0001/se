# 阶段 03 教师资料

阶段 03 直接从 React 开始，不先设置独立 JavaScript 阶段。学生先运行 [原生 JS 与 React 对比页](../03-1-对比原生与React/react-vs-native.html)，随后使用 Vite 建 React 页面，再连接阶段 02 的 FastAPI CRUD 接口。

## 教学重点

- 03-1 只运行、操作、比较，不把语法讲解放在前面；确保教室网络能加载对比页中的 jsDelivr 资源。
- 03-2 重点是组件、JSX、状态和事件；遇到 `.map()`、对象展开等 JavaScript 写法时即时解释，不安排脱离 React 的语法练习。
- 03-3 重点是 HTTP 请求、React 状态与服务器数据同步，以及受限的本地 CORS 配置。
- 阶段 02 的任务 02-3 必须完成四种报名 CRUD 接口后，学生才能进行 03-3。
- 使用虚构用户名 `user1`、`user2`，提醒学生不要把密钥或 `.env` 提交到仓库。
